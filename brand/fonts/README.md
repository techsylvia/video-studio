# Fonts

Drop the `.ttf` or `.otf` files for your captions and headlines here, then set their paths in
`brand/brand.json` under `fonts` (for example `"captions": "brand/fonts/Inter-Bold.ttf"`).

If this folder is empty, the editor falls back to a system font (Arial Bold or Helvetica on a Mac).
Only use fonts you are licensed to use in videos.
