# Edit a reel

Follow `prompts/edit-reel.md` in this project exactly. The clips to edit are the ones the creator
named after `/edit-reel` (for example `/edit-reel IMG_0412 IMG_0414`). If they named none, list
what is in `raw/` and ask which clips belong to this reel.

The rules in `AGENTS.md` (safety, style, brand) always apply. Never publish anything.
